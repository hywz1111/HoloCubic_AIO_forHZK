# 静音礼物版硬件与装配

适配目标：原始 HoloCubic / 当前 forHZK 引脚布局，ESP32-PICO-D4、4 MiB Flash、ST7789 240×240。以下引脚以仓库已有 `common.h`、屏幕配置及驱动为依据；采购的第三方改板仍需用其原理图核对，不能仅凭商品名称判断。

## 准备清单

| 部件 | 选择 |
| --- | --- |
| 主板与屏幕板 | 同一兼容版本的已焊板优先；自行焊接需逐项核对原理图与 BOM |
| 屏幕 | 1.3 英寸 ST7789，240×240，接口和背光电路与原版匹配 |
| TF 卡 | 建议质量可靠的 8/16/32 GB 卡，格式化为 FAT32；容量建议不代表已经逐款验证 |
| 光学件 | 与外壳匹配的分光棱镜，原方案 25.4 mm 立方；OCA 胶固定 |
| 外壳 | 与 PCB 版本匹配；保留 USB、TF 卡开口与散热空间 |
| 供电 | 合格的 5 V USB 电源，建议额定能力至少 1 A，配短且质量可靠的数据线 |
| 调试 | USB 转串口驱动、数据线、万用表；自行焊板另备烙铁/热风工具 |

无需新增喇叭、功放或音频模块。MPU6050、环境光传感器可保留在已有板上，礼物固件不会初始化或依赖它们。不要为省元件随意更改其余上拉、电源或下载电路。

桌面时钟、夜间模式、倒计时、纪念日和留言不需要新增硬件。设备没有断电保时能力，时钟由手机管理页校准；纯离线断电后仍可欣赏视频和留言，但需要重新打开管理页后才能恢复正确时间与夜间计划。

## 引脚核对

| 功能 | GPIO / 配置 |
| --- | --- |
| TFT MOSI / SCLK | 23 / 18，VSPI |
| TFT DC / RST | 2 / 4 |
| TFT CS | -1，固件无独立片选控制；对应原屏幕接法 |
| TFT MISO | 19（配置项，屏幕显示不依赖读回） |
| 屏幕背光 | 5，原板低电平点亮；PWM 反向控制 |
| TF SCK / MISO / MOSI / CS | 14 / 26 / 13 / 15，HSPI |
| RGB 灯 | 27，两个 WS2812，GRB 顺序 |
| MPU6050 与光感 | SDA32 / SCL33，本固件不使用 |

屏幕 SPI 起始使用 40 MHz，TF 卡使用 20 MHz，Flash 使用 DIO 40 MHz。保守时钟不等于所有改板都已验证。TF 初始化显式传入 GPIO26，无需修改全局 SPI 库。

默认屏幕亮度 55%，RGB 亮度约 8%，设置页灯光上限 40%，并做缓慢呼吸变化。亮度百分比不代表准确的功耗或温度。

## 供电和版本配套

- USB 5 V 接入板子的既定电源输入，不要直接接到 ESP32 的 3.3 V 引脚。
- 现有 LDO 版本应实测联网、播放时的压降和温升。电源额定 1 A 只表示供电能力，不表示设备会固定消耗 1 A。
- [原版设计资料](../Hardware/Original_HoloCubic/README.md) 内包含 Naive 与 Ironman 电路；原 Metal/Bilibili 外壳对应 Naive PCB，Ironman 外壳对应 Ironman PCB。
- 仓库[硬件版本说明](../硬件版本说明.md)提到的 AIO v2.0 主板、v2.1 DCDC 屏幕板为后续改版，不能当作已导入原版设计的版本号。若买改版，要求卖家提供对应原理图和装配说明。
- 不混焊 LDO 与 DCDC 方案。更改稳压方案要严格依据该版本电路，而非根据这份软件文档改线。
- 先裸板验证显示与播放，再粘棱镜和封壳；确认镜像方向正确后再贴 OCA 胶。

## 实机验收

编译通过不代表以下项目通过，送礼前需在最终装配件上逐项实测。

1. 检查短路、电源轨与稳压器装配，断电状态下插入 TF 卡，确认 USB 可正常烧录。
2. 不插卡启动，应显示清楚的「晗歌 / はづき」和橙色光点；不应卡在陀螺仪校准或配网界面。
3. 放入一段 240×240、12 fps 测试片。观察颜色、方向、棱镜镜像、播放连贯度；若不稳先检查供电与走线，再降低素材帧率。
4. 放入多段素材，检查排序轮播、手动切换、暂停/继续，以及重新通电后从上次手动选择的视频开头播放。
5. 用一段损坏视频和一段正常视频，检查损坏文件被跳过；全部损坏时应回到备用画面。不要在存有唯一素材的卡上测试。
6. 手机连接本机热点，验证无互联网提示下仍可打开管理页，播放中可以调亮度；添加、移除、重名拒绝及超限提示均正确。
7. 测试上传失败后的临时文件清理；确认原有文件仍可用。FAT32 写入中断电可能损坏文件系统，测试应使用可恢复的专用卡。
8. 视频播放和手机连接同时运行至少 2 小时，观察稳压器温升、是否重启、是否掉卡及亮度是否稳定。封壳后复测，不在发热异常的情况下交付。
9. 用 iPhone/Android 中实际准备使用的手机测试连接与上传，记录实际稳定帧率；本地网络权限、自动切回移动网络等差异需现场确认。
10. 随礼附电源、素材备份及一张使用卡，记录热点名、独立密码和 `http://192.168.4.1`；收礼人不需要安装开发环境。
11. 打开手机页面后确认自动校时、时区和日期正确；断电重启时，未校时前不能显示假时间或错误的纪念日天数。验证有卡、无卡两种情况。
12. 把夜间时段临时设为当前时间，检查屏幕降亮、底灯关闭；亮度 0 应熄屏，主动亮屏可以恢复，重新校时/保存计划后重新应用。检查跨午夜时段的开始与结束边界。
13. 启动 1 分钟计时，切换到 MV、熄屏、重新校时，确认结束仍然准确；亮屏后能看到到时提醒，结束后恢复所选展示。断电后不应错误恢复旧计时。另测上传期间计时结束的恢复显示。
14. 保存中日文留言和 3 个纪念日，在重启、无卡情况下检查保存与显示；检查每年重复、已过日期和闰年生日。播放 MV 至少 10 分钟确认穿插纪念卡后继续播放。
